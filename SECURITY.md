# Security policy

`aocd` runs as root and accepts requests from local users, so please report
security problems privately: use **GitHub → Security → Report a vulnerability**
on this repository, or email the maintainer listed in `packaging/meta.env`.

Please don't open public issues for:
- ways for a non-administrator to change settings or reach firmware commands
- crashes or hangs of `aocd` caused by socket input
- anything in the packaging that lowers system security

You can expect a first reply within a week. Supported versions: the latest release.
