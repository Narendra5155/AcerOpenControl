AcerOpenControl APT repository

Unofficial fan, keyboard and firmware control for Clevo-based Acer laptops. Not affiliated with or endorsed by Acer Inc.

curl -fsSL https://narendra5155.github.io/AcerOpenControl/key.gpg | sudo tee /usr/share/keyrings/acer-open-control.gpg >/dev/null
echo "deb [signed-by=/usr/share/keyrings/acer-open-control.gpg] https://narendra5155.github.io/AcerOpenControl stable main" \
  | sudo tee /etc/apt/sources.list.d/acer-open-control.list
sudo apt update
sudo apt install acer-open-control-gtk

Documentation and supported models: github.com/Narendra5155/AcerOpenControl
